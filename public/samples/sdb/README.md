# Beispiel-SDBs (Landingpage)

Die drei Hero-Buttons rufen bei `useMock: false` in `public/sdb-preview-config.json` die öffentliche Extraktions-API auf (`sampleKey`). Im Mock-Modus (`useMock: true`) kommen die Teaser aus dem Landing-Repo.

Echte PDF-Dateien können hier abgelegt werden, sobald die Public-Preview-API Beispiel-Keys unterstützt:

- `bremsenreiniger.pdf`
- `aceton.pdf`
- `epoxidharz2k.pdf`
